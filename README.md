# Hardware Diagnostics and Windows OS Deployment

## About This Portfolio

This portfolio documents my hands-on learning in computer hardware diagnostics, troubleshooting, and Windows operating system deployment.

The goal is to develop and demonstrate practical IT support and desktop support skills.

## Skills Being Developed

- Computer hardware identification and diagnostics
- RAM and storage troubleshooting
- HDD and SSD replacement concepts
- Windows installation and configuration
- Operating system imaging and deployment
- Driver installation and device troubleshooting
- Documentation and problem-solving

## Projects

### 1. Hardware Diagnostics

**Status:** In progress

Planned activities:
- Identify major computer components.
- Document a repeatable diagnostic process.
- Record symptoms, tests, findings, and corrective actions.
- Verify that the system operates correctly after repair.

### 2. Windows OS Deployment

**Status:** Planned

Planned activities:
- Document a Windows installation or deployment workflow.
- Record system requirements and installation steps.
- Verify drivers, updates, and device functionality.
- Document post-installation checks.

### 3. Troubleshooting Case Studies

**Status:** Planned

Each case study will describe:
- Problem and symptoms
- Environment and equipment
- Diagnostic steps
- Root cause, if established
- Resolution and verification
- Lessons learned

## Evidence and Documentation

Project evidence may include sanitized screenshots, diagrams,
